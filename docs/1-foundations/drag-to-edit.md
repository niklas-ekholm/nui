# Drag to Edit

#designpattern

Vertical scrub on labels, bar drag, handle resize — direct manipulation without modal dialogs.

## Purpose

Cross-element behaviour definition — edit values in place by dragging, not through separate dialogs.

## Rule

Draggable labels, bars, and handles update data live. Cursor may lock during scrub. No modal confirmation for range or date edits.
