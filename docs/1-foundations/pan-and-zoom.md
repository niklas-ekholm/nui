# Pan and Zoom

#designpattern

Space-drag pan, scroll pan, cmd/ctrl-wheel zoom, pinch zoom on chart views.

## Purpose

Cross-element behaviour definition — navigation in large canvases without modal controls.

## Rule

Chart views support drag-to-pan and zoom (wheel with modifier on desktop; pinch on touch). Pan shifts the visible range or viewport; zoom changes scale.
