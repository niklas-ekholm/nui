# Date Range

Parent: [[2-elements/timeline/index|Timeline]]

Visible window on the time axis. Display format: `DD.MM–DD.MM` (en dash, no spaces).

## Default

On first load: **3 weeks** starting Monday of the current week.

## Scrubbing

Drag either date label vertically to move that range edge. Uses [[scrub-label]].

## Restore

**⤶** resets to the default range and sets timespan preset back to **3 weeks**.

## Timespan menu

Selecting a preset sets how many days are visible and recenters on the midpoint of the current range.
